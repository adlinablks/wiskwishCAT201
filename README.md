# Wiskwish :birthday: - Custom Cake E-Commerce Platform 
Wiskwish is an e-commerce website specialising in handcrafted custom cakes designed for every special occasion. Customers can browse detailed product descriptions and view images along with customising their orders by selecting specific flavors, tiers and sizes to suit their celebration needs.

- GitHub Repo:  https://github.com/adlinablks/wiskwishCAT201.git

# Project Overview
This repository contains the source code for the Wiskwish website, including both the frontend and backend components.

# Features
:woman_technologist: User Management
- User Registration and Login
- Profile Management
- Session Management

:cake: Product Management
- Product Catalog
- Customization Options
- Real-time Inventory

:dollar: Shopping Cart and Checkout
- Add to Cart
- Cart Management
- Secure Checkout
- Order Summary
  
:shopping_cart:	Order Management
- Order Placement
- Order Confirmation

:gear: Admin Management
- Inventory Control
- Inventory Export
- Order Export

# Tech Stack
1. Frontend - HTML5, CSS3, JSP, Vanilla JavaScript
2. Backend - Jakarta Servlets (formerly Java Servlets), Maven, Tomcat 10
3. Data Storage - JSON File
4. Languages - Java, JSP, HTML, CSS, JavaScript
